contract snapshots and are not silently discharged.

the unchanged library baseline, including unregistered proof helpers. Contract
comparisons passed across 1,984 modules; see the repair report for the full scope.

outputs <= inputs. The remaining validity conditions are unchanged. The new rows' execution conclusions derive from the
existing actual C-call theorem, not from an assumed output or execution premise.
