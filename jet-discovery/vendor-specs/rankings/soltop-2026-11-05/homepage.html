Features

Everything you need to understand Solana program behavior

From real-time compute tracking to failure analysis, Soltop surfaces the insights that matter.

Compute Analytics

Track CU consumption across every program in real time. See trends, find heavy consumers, and monitor allocation efficiency at the slot level.

Failure Patterns

Detect error trends and failure modes during congestion. Identify which programs degrade under load and which transaction types are hit hardest.

Program Benchmarks

Compare success rates and CU efficiency across programs. Drill into individual dashboards with co-program analysis and fee impact breakdowns.

Use Cases

Built for everyone in the Solana ecosystem

Whether you ship code, run infrastructure, or study networks — Soltop gives you clarity.

01

Builders

See exactly how your program uses compute, spot inefficiencies in real time, and track success rates across transaction types. Monitor how your code interacts with other programs on-chain.

02

Validators

Understand which programs drive resource consumption during peak load. Analyze block composition, identify programs affecting network health, and plan capacity accordingly.

03

Researchers

Access structured on-chain analytics through a public API. Study program behavior patterns, congestion dynamics, and compute economics across the entire Solana network.
