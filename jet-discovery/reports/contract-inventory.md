# Data-ranked Ethereum and Solana demand inventory

Snapshot retrieval: 2026-11-04 America/Los_Angeles (UTC data timestamps below). The first set is the complete top 20 entries for **each chain** after sorting every entry in the saved DefiLlama `/protocols` response by its numeric `chainTvls[chain]`. This intentionally retains CEX holdings, liquid staking, bridges and other categories rather than silently substituting DefiLlama's default DeFi-only filter. Parent/child protocols can overlap; TVL is a demand signal, not an additive corpus weight.

The gas/compute sources are separate, explicitly bounded one-block snapshots. They are **not** a 24-hour popularity ranking. Etherscan Gas Tracker and Solscan Fee Tracker returned HTTP403 both through ordinary and escalated HTTP. Browser Harness failed to start and the in-app browser was unavailable. These explorer-period rankings therefore remain an access gap. The independently fetched complete blocks below retain a common, explicitly bounded snapshot. A separate [complete Ethereum UTC-day ranking](ETHEREUM-DAY-GAS-RANKING.md) reconciles all November 4, 2026 AWS mainnet receipt rows and publishes its own top 20 and all-recipient data. It does not replace the block table or the unavailable explorer view. No equivalent full-day Solana CU ranking is asserted.

Sources: [DefiLlama API](https://api.llama.fi/protocols), [Ethereum JSON-RPC](https://ethereum.org/en/developers/docs/apis/json-rpc/), [Solana getBlock](https://solana.com/docs/rpc/http/getblock), [Etherscan Gas Tracker](https://etherscan.io/gastracker), [Solscan Fee Tracker](https://solscan.io/analysis/fee-tracker). Raw responses and provenance are in `vendor-specs/contracts/`. UTXO mappings are architectural assessments from protocol categories and explicit source paths, not claims that these foreign protocols currently run on Bitcoin. Rebuild: `python3 tools/contract_inventory.py`.

## Time and oracle semantics: exact scope, not foreign-state equivalence

Bitcoin transaction `nLockTime` is a chosen lower bound on validity of the spend. If consensus accepts the transaction, the applicable chain height/time has reached that bound. The spender can choose an old bound. Checking`oracleTs <= txLockTime <= oracleTs +3600` therefore does **not** establish that a report is recent relative to the current chain tip or median time. No current-time primitive is invented here. The repository also does not provide an external Chainlink/Aave/Jupiter account-state root to authenticate their latest state.
