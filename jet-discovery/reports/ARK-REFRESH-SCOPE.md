## Exact implemented client statement

The client authenticates the negotiated old VTXO and liquidity UTXO, setup/cosign keys, requested new owner/value, peer/chain state and trusted tip800000. These are committed parameters, not unverified witness hints. This is a synthetic fixture under that authenticated view, not evidence of a live funding UTXO. The public certificate has one actual structured witness `(new_expiry, (unlock_preimage, four_final_signatures))`; it enters once and every reuse is through projections. The `Assert+Primitive` kernel contains zero Witness nodes and is evaluated through `boundProgram`.

The actual primitive transaction R has version2, one100000-satoshi authenticated P2TR liquidity input, sequenceFFFFFFFE, empty scriptSig/no annex, a79000-satoshi tree output and20000-satoshi server change, giving1000-satoshi fee. Its tree root uses sorted MuSig2 aggregate cosign keys and a minimally encoded server CLTV expiry leaf. D is a real version3 transaction spending R:0 with sequence0, creating49000/30000-satoshi new/other hash-locked leaves and a zero-value P2A anchor. L spends D:0 under the actual aggregate-key hash/unlock scriptpath and produces the requested user's49000-satoshi ordinary VTXO plus P2A anchor. F spends the authenticated prior50000-satoshi VTXO and creates an equal-value current hArk forfeit output plus P2A anchor. The forfeit preserves the old user's CSV144 recovery clause and the server's shared-hash claim. All four exact DEFAULT messages/final signatures, all linked raw txids, scripts and values are checked.

Every expiry-dependent TapLeaf/TapBranch/TapTweak is computed in Simplicity. Expiry must be a minimal positive three-byte Script number,65536..2^23-1, and satisfy `trusted_tip + 2*exit_margin + old_exit_delta = 800432`. The same single32-byte preimage determines both the new user's leaf and the server's forfeit hash clause. The actual current HashSign prefix is OP_SIZE32/OP_HASH160, with RIPEMD160(SHA256(preimage)); no legacy ECDSA/connector profile is substituted.

The codec reconstructs all four standard signed Bitcoin wire transactions, including L's actual64-byte signature,32-byte preimage,61-byte script and65-byte control block. `hark-derived-package.tsv` and `hark-derived-context.tsv` in Growth3 preserve them.
