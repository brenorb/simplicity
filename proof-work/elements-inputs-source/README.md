# Elements inputsHash canonical-source boundary

The fixed model pins the complete new program, raw digest expression and C
theorem statement, plus the literal Haskell composition. The source checker
also checks catalog routing, wrapper/type, and the complete original C getter.
The previously reviewed outpoints, annexes and sequence-loop source guards are
reused; the composition introduces no new primitive.

`SOURCE-REVIEW.json` and exact positive/negative logs record successful source
review, including26 read-only composition/component/raw-digest/C/contract
corruptions. Both program-level digest order and64-/32-byte chunk widths are
guarded. An initial ambiguous source-block anchor (the library mapping has a
similarly named field) was rejected; the fixed model selects the unique real
program clause, not the mapping.

This is a source-fidelity check, not a kernel check, proof of actual caller
cache construction, formal host-library verification, or accepted coverage.
