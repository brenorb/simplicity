# Normal-C contract snapshot and deep supplements

The high-depth driver uses the same full import context and `Set Printing All`
as the normal contract gate. It yields all 178 types and 113 non-tree
definitions without ellipses. Normal-depth retained fragments match the deep
supplements in order, with anchored suffixes for nested binary numerals. This
is a printing diagnostic, not a proof of equality of omitted terms. The
actual sources are hash-pinned namespace transports and compiled; execution,
arithmetic, ownership and shape results have independent OriginalC kernel
receipts. Full normal-C kernel/acceptance still must pass.

Seven `_tree` definitions are diagnostic executor representations. Their
normal snapshot records stay registered and frozen. We do not replace any
execution proof with tree text: the source hashes and actual run/shape
theorems establish the required execution witnesses. No theorem is skipped.

One name occurs in both old and new inventories: `u128_field`. The inherited
`C.jet_u128_fields` definition prints unqualified, whereas the new one prints
`jet_secp_u128_shift64_expr.u128_field`. The reviewer distinguishes those exact
headers, preserves the inherited record in full and never strips arbitrary
namespaces or merges records into a name-only dictionary.

The public type was inspected untruncated: it is exactly `secp_jet_local_spec`
for `jets_secp.f_simplicity_scalar_is_zero`, Word256 -> Bit, with
`canonical_scalar_is_zero Alg.CoreFunSem`. The whole-call theorem starts from
the intended local output/source/input/cursor contracts, not assumed helper
execution or desired output/free. It concludes the actual original C call,
encoded literal output, and the external frame. Both literal scalar programs
also have compiled Core.Parametric results. Canonical source and recursive
dependency gates pass independently.
