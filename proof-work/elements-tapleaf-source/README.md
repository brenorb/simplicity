native word/four-limb hash decoding, primitive port and SHA/getter contracts.

`TapLeaf/elements` tagged-context helper, literal ASCII tag, repeated tag digest,

original C getter and the entire separated C-to-program theorem.

digest duplication, context count, helper libraries, primitive identities and
carriers, version/CMR selection, byte vector lengths, C fields and all important

register a jet or constitute full normal acceptance. Those evidence stages
remain separate.
