# Review witness sources

These 19 complete sources preserve inherited Bitcoin boundary diagnostics,
frame endpoint and same-block witnesses, range-separated helper proofs, and
secp statement/assumption inspection commands. They are evidence sources,
not registrations or an exhaustive fidelity certificate.

The original report files describe their scopes and historical checks. Some
witnesses refer to the former contract that they diagnose and must be replayed
against that revision, rather than the corrected contract. Others require the
field predicate candidate in the `OriginalC` namespace. Exact sources remain
archived; namespace and revision selection must be reviewed before reuse.
