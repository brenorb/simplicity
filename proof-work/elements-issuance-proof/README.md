## Important cases proved in the Coq model

An out-of-range input index has the outer absent tag. An **in-range** input
without an issuance instead returns the digest of empty proof bytes. New
issuances select their asset or token amount proof. A reissuance's asset
proof comes from its amount, whereas its token proof view is empty. An
explicit amount has an empty proof view; a confidential amount has its
stored proof bytes. The two pure lemmas cover all these cases universally,
not by sample execution or an informal assertion.

Index/digest conversion and current-input assertion semantics reuse
`C.jet_elements_script_hash_literal.elements_input_digest_literal_matches`
and `C.jet_elements_current_sequence_literal.elements_current_literal_sem`.
The C execution proof is transported in its entirety, preserving original
separated frames, arbitrary output contents, cursor/prefix, environment and
memory-change contracts. The represented cached fields are at input offsets
360 and 392 (issuance base 256 plus 104 and 136). The existing
`Digest.byteStringHash` model and LP64/RECKLESS scope are unchanged. Cached
digest construction by real callers is not established here.
